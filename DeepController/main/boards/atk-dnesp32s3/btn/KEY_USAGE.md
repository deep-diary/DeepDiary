# 按键功能说明文档

## 概述

本文档说明 ATK-DNESP32S3 开发板上按键的功能和使用方法。

## 按键定义

### KEY0 按键（用户按键）

- **GPIO 引脚**: `GPIO_NUM_2`
- **功能**: 唤醒/休眠控制
- **触发方式**: 低电平触发（按下为低电平）

### BOOT 按键（系统按键）

- **GPIO 引脚**: `GPIO_NUM_0`
- **功能**: 系统启动按键（保留用于系统功能）
- **触发方式**: 低电平触发（按下为低电平）

## 功能说明

### KEY0 按键功能

KEY0 按键用于控制设备的唤醒和休眠状态：

#### 1. 从休眠中唤醒

当设备处于浅睡眠模式时：
- **操作**: 按下 KEY0 按键
- **行为**: 
  - 从浅睡眠中唤醒
  - 自动唤醒 xiaozhi（调用 `WakeWordInvoke("你好小智")`）
  - 等待 2 秒后进入监听状态

#### 2. 进入休眠模式

当设备处于正常工作状态时：
- **操作**: 按下 KEY0 按键
- **前提条件**: 设备必须处于空闲状态（`CanEnterSleepMode()` 返回 `true`）
- **行为**:
  - 关闭音频输入和唤醒词检测
  - 关闭音频编解码器输入
  - 配置 KEY0 按键为唤醒源（低电平触发）
  - 进入浅睡眠模式（`esp_light_sleep_start()`）
  - 从浅睡眠唤醒后，自动恢复音频输入和唤醒词检测

#### 3. 设备忙碌时

如果设备正在使用中（如正在播放音频、处理任务等），按下 KEY0 按键不会进入休眠模式，日志会显示：
```
设备正在使用中，无法进入休眠
```

## 代码实现

### 按键初始化

在 `user_main_loop_task` 函数开始时调用：
```c
key_init();  // 初始化按键
```

### 按键扫描

在主循环中使用轮询方式扫描按键：
```c
uint8_t key_val = key_scan(0);  // 不支持连续按
if (key_val == KEY0_PRES) {
    // 处理 KEY0 按键事件
}
```

### 按键扫描函数说明

```c
uint8_t key_scan(uint8_t mode);
```

**参数**:
- `mode = 0`: 不支持连续按（按键按下不放时，只有第一次调用会返回键值）
- `mode = 1`: 支持连续按（按键按下不放时，每次调用都会返回键值）

**返回值**:
- `KEY0_PRES` (2): KEY0 按键按下
- `BOOT_PRES` (1): BOOT 按键按下
- `0`: 没有按键按下

## 硬件连接

### KEY0 按键电路

```
KEY0 按键连接到 GPIO_NUM_2
- 按下时：GPIO 为低电平（0）
- 松开时：GPIO 为高电平（1，内部上拉）
```

### 修改按键引脚

如果需要修改 KEY0 按键的 GPIO 引脚，请编辑 `key.h` 文件：

```c
#define KEY0_GPIO_PIN   GPIO_NUM_2      // 修改为其他 GPIO 引脚
```

**注意**: 
- 确保选择的 GPIO 引脚支持外部唤醒功能
- 确保选择的 GPIO 引脚没有被其他功能占用
- 修改后需要重新编译和烧录固件

## 休眠唤醒机制

### 浅睡眠模式

设备使用 ESP32-S3 的浅睡眠模式（Light Sleep）：
- **功耗**: 显著降低功耗，但保持 RTC 和部分外设工作
- **唤醒时间**: 唤醒时间短（毫秒级）
- **唤醒源**: KEY0 按键（GPIO 外部唤醒）

### 唤醒源配置

```c
esp_sleep_enable_ext0_wakeup(KEY0_GPIO_PIN, 0);  // 低电平触发
```

**参数说明**:
- `KEY0_GPIO_PIN`: 唤醒源 GPIO 引脚
- `0`: 触发电平（0 = 低电平，1 = 高电平）

- **进入休眠**: `"按键按下：进入休眠模式"`
- **唤醒**: `"按键按下：从休眠中唤醒并询问时间"`
- **设备忙碌**: `"设备正在使用中，无法进入休眠"`
- **浅睡眠**: `"进入浅睡眠模式，按KEY0键唤醒"`

### 常见问题

#### Q: 按键按下没有反应？

**检查清单**:
1. 确认 `key_init()` 已正确调用
2. 检查 GPIO 引脚配置是否正确
3. 检查按键硬件连接
4. 查看日志确认按键扫描是否正常工作

#### Q: 无法进入休眠模式？

**可能原因**:
1. 设备正在使用中（播放音频、处理任务等）
2. `CanEnterSleepMode()` 返回 `false`
3. 查看日志确认具体原因

#### Q: 从休眠唤醒后没有自动唤醒 xiaozhi？

**检查清单**:
1. 确认 `is_sleep_mode` 标志位正确设置
2. 检查 `WakeWordInvoke()` 是否正常调用
3. 查看日志确认唤醒流程

## 扩展功能

### 添加更多按键

如果需要添加更多按键，请参考以下步骤：

1. **在 `key.h` 中定义新按键**:
```c
#define KEY1_GPIO_PIN   GPIO_NUM_X      // 新按键引脚
#define KEY1            gpio_get_level(KEY1_GPIO_PIN)
#define KEY1_PRES       3               // 新按键键值
```

2. **在 `key_init()` 中配置新按键**:
```c
gpio_init_struct.pin_bit_mask = (1ull << KEY0_GPIO_PIN) | (1ull << KEY1_GPIO_PIN);
```

3. **在 `key_scan()` 中添加扫描逻辑**:
```c
if (KEY1 == 0) {
    keyval = KEY1_PRES;
}
```

4. **在主循环中处理新按键事件**:
```c
if (key_val == KEY1_PRES) {
    // 处理 KEY1 按键事件
}
```
