# 语音通信处理器使用说明

## 概述

语音通信处理器 (`VoiceCommunicationHandler`) 是 DeepWin 系统中专门处理语音服务发出信号的模块。它负责接收语音命令，解析 commands，并将命令转发到相应的设备模块。

## 功能特性

1. **语音命令接收**: 接收并解析语音服务返回的 commands
2. **命令分类处理**: 根据命令类型自动分类并转发到相应设备
3. **信号连接**: 与协调器系统集成，实现统一的信号管理
4. **错误处理**: 完善的错误处理和日志记录机制

## 架构设计

### 信号定义

```python
# 语音命令接收信号
voice_command_received = Signal(dict)  # (command_data)

# 语音状态更新信号  
voice_status_updated = Signal(str, dict)  # (status_type, status_data)

# 语音错误信号
voice_error_occurred = Signal(str, str)  # (error_type, error_message)
```

### 命令处理流程

```
语音响应 → 提取commands → 解析JSON → 分类处理 → 转发到设备
    ↓
记录日志 → 状态更新 → 错误处理
```

## 使用方法

### 1. 基本使用

```python
from src.app_logic.core_manager.handler.voice_communication_handler import VoiceCommunicationHandler

# 创建处理器实例
voice_handler = VoiceCommunicationHandler()

# 处理语音响应
payload = {
    "output": {
        "extra_info": {
            "commands": '[{"name":"motor_increase_pos","params":[]}]'
        }
    }
}

voice_handler.process_voice_response(payload)
```

### 2. 在 ChatCallback 中使用

```python
def on_responding_content(self, payload: Dict[str, Any]):
    try:
        # 使用语音通信处理器处理commands
        self._process_commands_with_handler(payload)
        
        # 保留原有的命令处理逻辑作为备用
        self._process_commands_directly(payload)
        
    except Exception as e:
        logger.error(f"处理语音响应时发生错误: {str(e)}")
        return
```

### 3. 自定义命令处理

```python
# 处理电机命令
def _handle_motor_command(self, command_name: str, params: list):
    logger.info(f"处理电机命令: {command_name}")
    
    # 添加具体的电机控制逻辑
    if command_name == "motor_increase_pos":
        # 执行电机位置增加操作
        pass
    
    # 发送设备状态更新信号
    self.coordinator_handler.device_status_updated.emit("motor", {
        "command": command_name,
        "params": params,
        "status": "executing"
    })
```

## 命令格式

### 标准命令结构

```json
{
    "name": "command_name",
    "params": [
        {
            "name": "param_name",
            "value": "param_value",
            "normValue": "normalized_value"
        }
    ]
}
```

### 支持的命令类型

1. **电机命令** (`motor_*`)
   - `motor_increase_pos`: 电机位置增加
   - `motor_decrease_pos`: 电机位置减少
   - `motor_set_speed`: 设置电机速度

2. **机械臂命令** (`arm_*`)
   - `arm_move_to`: 移动到指定位置
   - `arm_grab`: 抓取操作
   - `arm_release`: 释放操作

3. **玩具命令** (`toy_*`)
   - `toy_play`: 播放玩具
   - `toy_stop`: 停止玩具

4. **通用命令**
   - `increase_volume_default`: 增加音量
   - `decrease_volume_default`: 减少音量

## 集成说明

### 1. 自动发现

语音通信处理器会被协调器自动发现和初始化，无需手动注册。

### 2. 依赖注入

处理器通过 `set_coordinator_dependencies()` 方法自动获取所需的依赖项：

- `logger`: 日志管理器
- `coordinator_handler`: 协调器处理器
- `device_logic_manager`: 设备逻辑管理器

### 3. 信号连接

处理器会自动连接相关信号，实现与协调器系统的集成。

## 扩展开发

### 添加新命令类型

1. 在 `_forward_command_to_device()` 方法中添加新的命令类型判断
2. 创建对应的处理方法（如 `_handle_new_device_command()`）
3. 在处理方法中实现具体的业务逻辑

### 添加新的信号

1. 在类中定义新的信号
2. 在 `_connect_signals()` 方法中连接信号
3. 创建对应的槽函数处理信号

## 注意事项

1. **错误处理**: 所有操作都包含在 try-catch 块中，确保系统稳定性
2. **日志记录**: 重要操作都会记录日志，便于调试和监控
3. **信号发射**: 使用 `emit_*` 方法发射信号，确保信号正确传递
4. **依赖检查**: 在初始化时验证必需的依赖项是否已设置

## 故障排除

### 常见问题

1. **依赖项缺失**: 检查是否所有必需的依赖项都已正确设置
2. **信号未连接**: 确认信号连接是否在 `_connect_signals()` 方法中完成
3. **命令解析失败**: 检查 commands JSON 格式是否正确

### 调试方法

1. 查看日志输出，了解处理流程
2. 使用测试脚本验证基本功能
3. 检查信号连接状态
