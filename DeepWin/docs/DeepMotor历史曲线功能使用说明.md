# DeepMotor 历史曲线功能使用说明

## 概述

DeepMotor 页面现在支持历史曲线显示功能，可以实时显示电机参数的历史变化趋势，帮助用户进行数据分析和监控。

## 功能特性

### 1. 参数选择

- 支持选择不同的电机参数进行曲线显示
- 可选择的参数包括：
  - **位置 (position)** - 电机当前位置，单位：度 (°)
  - **速度 (velocity)** - 电机当前速度，单位：度/秒 (°/s)
  - **扭矩 (torque)** - 电机当前扭矩，单位：牛·米 (N·m)
  - **温度 (temperature)** - 电机当前温度，单位：摄氏度 (°C)
  - **错误码 (error_code)** - 电机错误状态码
  - **CAN ID (motor_can_id)** - 电机 CAN 总线 ID

### 2. 实时曲线显示

- 横坐标：时间（自动格式化显示）
- 纵坐标：选中参数的具体数值
- 支持网格显示，便于读数
- 自动调整坐标轴范围

### 3. 数据管理

- 自动保存历史记录（默认 100 条）
- 支持动态调整历史记录长度
- 实时更新曲线显示

## 使用方法

### 1. 基本操作

#### 选择参数

1. 在"选择参数"下拉框中选择要显示的参数
2. 系统会自动刷新曲线显示
3. 曲线标题和单位会自动更新

#### 刷新曲线

1. 点击"刷新曲线"按钮
2. 系统会重新获取最新的历史数据
3. 曲线会更新为最新的状态

### 2. 曲线解读

#### 位置曲线

- **上升趋势**：电机正向旋转
- **下降趋势**：电机反向旋转
- **水平线**：电机静止
- **波动**：电机在振荡或定位过程中

#### 速度曲线

- **正值**：正向旋转
- **负值**：反向旋转
- **零值**：电机停止
- **变化率**：加速度信息

#### 温度曲线

- **上升趋势**：电机工作负载增加
- **稳定值**：正常工作温度
- **过高值**：可能过热，需要检查

#### 扭矩曲线

- **变化趋势**：负载变化情况
- **峰值**：最大负载时刻
- **平均值**：正常工作负载

### 3. 高级功能

#### 时间范围分析

- 曲线显示最近的历史数据
- 时间轴自动格式化显示
- 支持查看不同时间段的数据

#### 数据统计

- 自动计算数值范围
- 显示数据点数量
- 支持趋势分析

## 技术实现

### 1. 数据流程

```
电机状态更新 → 历史记录保存 → 参数选择 → 数据查询 → 曲线绘制
```

### 2. 核心组件

- **DeepMotorPage**: 主界面组件
- **matplotlib**: 曲线绘制引擎
- **FigureCanvas**: Qt 集成组件
- **历史记录系统**: 数据存储和查询

### 3. 信号连接

```python
# 历史数据请求信号
request_history_data = Signal(str, str)  # (设备名, 参数名)

# 历史数据更新方法
update_history_curve(history_data)
```

## 配置说明

### 历史记录长度配置

在 `config/config.json` 中设置：

```json
{
  "device_settings": {
    "deepmotor_history_length": 100
  }
}
```

## 注意事项

### 1. 性能考虑

- 历史记录数量影响内存使用
- 曲线更新频率影响 CPU 使用
- 建议根据实际需求调整记录长度

### 2. 数据准确性

- 确保电机数据正常更新
- 检查网络连接状态
- 验证数据源可靠性

### 3. 显示效果

- 中文字体可能需要额外配置
- 曲线颜色和样式可自定义
- 支持主题切换

## 故障排除

### 1. 曲线不显示

- 检查是否有历史数据
- 验证参数选择是否正确
- 确认 matplotlib 是否正确安装

### 2. 数据不更新

- 检查电机连接状态
- 验证数据更新频率
- 确认信号连接正常

### 3. 显示异常

- 检查中文字体支持
- 验证 matplotlib 版本
- 确认 Qt 集成正常
