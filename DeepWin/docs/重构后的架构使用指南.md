# 重构后的架构使用指南

## 🎯 **重构目标**

简化调用链路，让架构更清晰：

- **DeviceLogicManager**：设备管理和通用能力调用
- **DeepMotor**：电机核心逻辑
- **TeachingCapability**：示教能力实现
- **UI 层**：直接调用能力或使用通用接口

## 📋 **新的调用方式**

### 1. **直接访问能力（推荐）**

```python
# 获取设备实例
motor = device_manager.deep_motor

# 示教相关操作
motor.teaching_capability.start_teaching("DeepMotor", 1)
motor.teaching_capability.stop_teaching("DeepMotor")
motor.teaching_capability.execute_trajectory("DeepMotor", "trajectory_name", 1, True)

# 获取轨迹列表
trajectory_list = motor.teaching_capability.get_trajectory_list("DeepMotor")

# 获取历史数据
historical_data = motor.get_historical_data("position", {})
trajectory_data = motor.get_historical_data("trajectory_both", {"trajectory_name": "trajectory_name"})
```

### 2. **通用能力调用**

```python
# 适用于动态设备或非核心设备
device_manager.call_device_capability("DeepMotor", "teaching", "start_teaching", "DeepMotor", 1)
device_manager.call_device_capability("DeepMotor", "teaching", "stop_teaching", "DeepMotor")
device_manager.call_device_capability("DeepMotor", "teaching", "get_trajectory_list", "DeepMotor")
```

### 3. **获取设备能力信息**

```python
# 查看设备支持的所有能力
capabilities = device_manager.get_device_capabilities("DeepMotor")
print(capabilities)  # {'teaching': ['start_teaching', 'stop_teaching', ...]}

# 查看能力支持的方法
methods = motor.get_capability_methods("teaching")
print(methods)  # {'start_teaching': <function>, 'stop_teaching': <function>, ...}
```

## 🔧 **UI 层更新示例**

### 原来的调用方式（已删除）

```python
# ❌ 不再支持
device_manager.start_teaching("DeepMotor", 1)
device_manager.stop_teaching("DeepMotor")
device_manager.execute_trajectory("DeepMotor", "trajectory_name", 1, True)
```

### 新的调用方式

```python
# ✅ 推荐方式
motor = device_manager.deep_motor
motor.teaching_capability.start_teaching("DeepMotor", 1)
motor.teaching_capability.stop_teaching("DeepMotor")
motor.teaching_capability.execute_trajectory("DeepMotor", "trajectory_name", 1, True)

# ✅ 通用方式
device_manager.call_device_capability("DeepMotor", "teaching", "start_teaching", "DeepMotor", 1)
```

## 🏗️ **架构优势**

### 1. **职责清晰**

- **DeviceLogicManager**：只负责设备管理和通用接口
- **DeepMotor**：专注于电机控制逻辑
- **TeachingCapability**：专门处理示教功能

### 2. **调用简洁**

- 直接访问：`motor.teaching_capability.start_teaching()`
- 通用调用：`device_manager.call_device_capability()`

### 3. **易于扩展**

- 新增能力只需实现 `DeviceCapability` 接口
- 新增设备无需修改管理器代码

### 4. **类型安全**

- IDE 可以提供完整的代码补全
- 编译时就能发现错误

## 📝 **迁移指南**

### 需要更新的地方

1. **UI 层调用**：更新所有示教相关的方法调用
2. **协调器层**：使用新的调用方式
3. **测试代码**：更新测试用例

### 迁移步骤

1. 找到所有 `device_manager.start_teaching()` 等调用
2. 替换为 `motor.teaching_capability.start_teaching()`
3. 更新方法参数（注意设备 ID 参数）
4. 测试功能是否正常

## 🎉 **总结**

重构后的架构更加：

- **简洁**：减少了不必要的委托层
- **清晰**：职责分离明确
- **灵活**：支持多种调用方式
- **可维护**：代码结构更合理
