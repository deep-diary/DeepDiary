# DeepWin 数据库协调器测试指南

## 概述

本文档介绍如何使用 DeepWin 数据库协调器进行数据库创建、写入和功能测试。协调器支持 SQLite 关系数据库和 Qdrant 向量数据库的协同工作。

## 功能特性

### 1. SQLite 数据库功能

- 用户管理（UserModel）
- 需求管理（NeedModel）
- 资源管理（ResourceModel）
- 照片管理（PhotoModel）
- 事务支持
- 自动表结构创建

### 2. Qdrant 向量数据库功能

- 用户嵌入向量存储
- 记忆嵌入向量存储
- 照片嵌入向量存储
- 向量搜索和检索
- 集合管理

### 3. 跨数据库协调

- 统一的数据管理接口
- 事务一致性保证
- 状态监控和报告

## 使用方法

### 1. 基本初始化

```python
from deepwin.app_logic.core_manager.coordinator import Coordinator
from deepwin.data_management.log_manager import LogManager

# 初始化日志管理器
log_manager = LogManager()

# 初始化协调器
coordinator = Coordinator(log_manager=log_manager)
```

### 2. 创建示例数据

```python
# 创建SQLite示例数据
sqlite_result = coordinator.create_sqlite_database_and_add_sample_data()

# 创建Qdrant示例数据
qdrant_result = coordinator.create_qdrant_database_and_add_sample_data()
```

### 3. 测试数据库功能

```python
# 测试所有数据库功能
test_result = coordinator.test_database_functionality()

# 获取数据库摘要信息
summary = coordinator.get_database_summary()
```

## 配置要求

### 环境依赖

- Python 3.8+
- PySide6
- SQLAlchemy
- qdrant-client
- langchain-community

### 配置文件

确保 `config.json` 包含正确的数据库配置：

```json
{
  "database": {
    "sqlite": {
      "path": "deepwin.db",
      "echo": false
    },
    "qdrant": {
      "host": "localhost",
      "port": 6333,
      "local_path": "./database/qdrant",
      "web_ui_enabled": true
    }
  }
}
```

## 故障排除

### 常见问题

1. **数据库连接失败**

   - 检查配置文件中的数据库路径
   - 确保有足够的文件系统权限
   - 验证网络连接（远程数据库）

2. **模型导入错误**

   - 检查 Python 路径设置
   - 验证模型文件的完整性
   - 确保所有依赖包已安装

3. **异步操作问题**
   - 检查事件循环状态
   - 使用线程池执行器处理阻塞操作
   - 验证异步函数的正确性

### 日志信息

协调器提供详细的日志记录，包括：

- 初始化过程
- 数据库操作状态
- 错误和异常信息
- 性能指标

## 扩展开发

### 添加新的数据模型

1. 在 `models/` 目录下创建新的模型文件
2. 在 `model_initializer.py` 中注册新模型
3. 在协调器中添加相应的示例数据
4. 更新测试用例

### 自定义数据库操作

1. 继承 `BaseDatabase` 类
2. 实现必要的接口方法
3. 在 `DatabaseFactory` 中注册新数据库类型
4. 更新协调器的初始化逻辑

## 性能优化

### 建议

- 使用连接池管理数据库连接
- 批量插入大量数据
- 异步处理长时间运行的操作
- 定期清理临时数据和日志

### 监控指标

- 数据库连接数
- 查询响应时间
- 内存使用情况
- 磁盘 I/O 性能
