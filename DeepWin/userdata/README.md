# 用户数据目录 (User Data Directory)

## 概述

`userdata` 目录是 DeepWin 系统中用户数据的集中存储位置，用于存放用户生成或上传的各种类型数据，包括图片、视频、音频、GPS 轨迹等多媒体和位置信息。

## 目录结构

```
userdata/
├── README.md          # 本说明文档
├── img/              # 图片数据存储
├── video/            # 视频数据存储 (注意：目录名应为 video)
├── audio/            # 音频数据存储
├── gps/              # GPS轨迹数据存储
├── wechat/           # 微信相关数据存储
└── rag/              # RAG (检索增强生成) 相关数据
```

## 各子目录详细说明

### 📸 img/ - 图片数据

**用途**: 存储用户上传或系统生成的图片文件
**支持格式**: JPG, PNG, GIF, BMP, WebP 等常见图片格式
**数据结构**:

- 按日期或主题分类存储
- 支持元数据标注（拍摄时间、地点、标签等）
- 自动生成缩略图用于快速预览

### 🎬 vidio/ - 视频数据

**用途**: 存储用户上传或录制的视频文件
**支持格式**: MP4, AVI, MOV, MKV, WebM 等常见视频格式
**数据结构**:

- 按录制时间或内容类型分类
- 支持视频分段和关键帧提取
- 自动生成视频预览图

### 🎵 audio/ - 音频数据

**用途**: 存储用户录制的音频文件或语音数据
**支持格式**: MP3, WAV, FLAC, AAC, OGG 等常见音频格式
**数据结构**:

- 按录制时间或内容类型分类
- 支持音频转写和关键词提取
- 自动生成音频波形图

### 🗺️ gps/ - GPS 轨迹数据

**用途**: 存储用户的 GPS 定位轨迹和位置信息
**支持格式**: GPX, KML, JSON, CSV 等轨迹文件格式
**数据结构**:

- 按日期或行程分类存储
- 包含时间戳、经纬度、海拔、速度等信息
- 支持轨迹可视化和统计分析

### 💬 wechat/ - 微信数据

**用途**: 存储从微信导出的聊天记录、图片、语音等数据
**支持格式**: 文本、图片、音频、视频等多种格式
**数据结构**:

- 按聊天对象或时间分类
- 支持聊天记录搜索和关键词提取
- 自动识别和分类不同类型的消息

### 🔍 rag/ - RAG 数据

**用途**: 存储检索增强生成相关的向量索引和知识库数据
**支持格式**: FAISS 索引、向量数据库、文档等
**数据结构**:

- 向量索引文件
- 知识库文档
- 元数据索引
- 查询历史记录

## 数据管理策略

### 存储策略

- **分层存储**: 按数据类型和访问频率进行分层存储
- **压缩优化**: 对大型文件进行压缩存储，节省空间
- **备份机制**: 定期备份重要数据，防止数据丢失

### 访问控制

- **权限管理**: 根据用户角色设置不同的数据访问权限
- **隐私保护**: 敏感数据加密存储，保护用户隐私
- **审计日志**: 记录数据访问和修改操作，便于追踪

### 性能优化

- **缓存机制**: 对频繁访问的数据进行缓存
- **索引优化**: 建立高效的数据索引，提高查询速度
- **负载均衡**: 根据数据大小和访问模式进行存储分布

## 使用说明

### 数据上传

1. 通过 DeepWin 应用程序界面上传文件
2. 支持拖拽上传和批量上传
3. 自动识别文件类型并分类存储

### 数据查询

1. 使用关键词搜索功能查找特定数据
2. 按时间、类型、标签等条件筛选
3. 支持高级搜索和组合查询

### 数据导出

1. 支持多种格式的数据导出
2. 可选择导出单个文件或批量导出
3. 支持数据格式转换

## 注意事项

### 存储空间

- 定期清理不需要的数据文件
- 监控存储空间使用情况
- 建议定期进行数据整理和归档

### 数据安全

- 重要数据建议进行多重备份
- 定期检查数据完整性
- 避免在公共网络环境下传输敏感数据

### 性能考虑

- 大量数据文件可能影响系统性能
- 建议定期进行数据优化和清理
- 考虑使用外部存储设备扩展存储空间
