# TCP 视频流客户端使用说明

## 功能描述

这个 TCP 视频流客户端可以从摄像头捕获视频流，将视频帧编码为 JPEG 格式，并通过 TCP 协议发送到指定的服务器。

## 主要特性

- 🎥 **摄像头支持**: 自动检测可用的摄像头设备
- 📡 **TCP 连接**: 稳定的 TCP 连接，支持自动重连
- 🖼️ **JPEG 编码**: 高效的 JPEG 压缩，可调节质量
- ⚙️ **配置管理**: 支持 JSON 配置文件
- 📊 **实时统计**: 显示传输统计信息
- 🔄 **错误处理**: 完善的错误处理和重连机制
- 👁️ **实时预览**: 可选的视频预览窗口

## 使用方法

### 1. 基本使用

```bash
cd DeepWin/deepwin/tests
python test_tcp_client.py
```

### 2. 配置文件

程序会自动查找 `tcp_client_config.json` 配置文件。如果不存在，会使用默认配置。

配置文件示例：

```json
{
  "server": {
    "host": "35.192.64.247",
    "port": 8080
  },
  "camera": {
    "width": 640,
    "height": 480,
    "fps": 30,
    "jpeg_quality": 80
  },
  "connection": {
    "max_retry_count": 3,
    "retry_delay": 2.0,
    "timeout": 10
  }
}
```

### 3. 配置参数说明

#### 服务器配置

- `host`: 服务器 IP 地址
- `port`: 服务器端口号

#### 摄像头配置

- `width`: 视频宽度（像素）
- `height`: 视频高度（像素）
- `fps`: 帧率
- `jpeg_quality`: JPEG 压缩质量（1-100）

#### 连接配置

- `max_retry_count`: 最大重试次数
- `retry_delay`: 重试延迟（秒）
- `timeout`: 连接超时时间（秒）

## 数据格式

### TCP 数据包格式

每个视频帧的 TCP 数据包格式如下：

```
[帧大小(4字节)][JPEG数据]
```

- 帧大小：使用网络字节序（大端序）的 4 字节无符号整数
- JPEG 数据：压缩后的 JPEG 图像数据

## 控制操作

- 按 `q` 键：停止视频流传输
- 按 `Ctrl+C`：强制退出程序

## 注意事项

1. 确保摄像头设备可用且未被其他程序占用
2. 确保网络连接正常，服务器地址和端口正确
3. 建议在稳定的网络环境下使用
4. 如果遇到连接问题，程序会自动尝试重连

## 故障排除

### 常见问题

1. **摄像头无法打开**

   - 检查摄像头是否被其他程序占用
   - 尝试不同的摄像头索引（0, 1, 2...）

2. **连接服务器失败**

   - 检查网络连接
   - 确认服务器地址和端口正确
   - 检查防火墙设置

3. **视频质量不佳**

   - 调整 `jpeg_quality` 参数（1-100）
   - 降低视频分辨率或帧率

4. **传输卡顿**
   - 降低帧率或分辨率
   - 检查网络带宽
   - 增加重试延迟时间
