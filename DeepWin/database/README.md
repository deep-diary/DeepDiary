# DeepWin 数据库文件夹结构

## 📁 文件夹说明

### `sqlite/`

- **用途**: 存放 SQLite 数据库文件
- **文件类型**: `.db`, `.sqlite`, `.sqlite3`
- **说明**: 关系型数据库文件，包含用户、需求、资源、照片等结构化数据

### `qdrant/`

- **用途**: 存放 Qdrant 向量数据库文件
- **文件类型**: 文件夹结构，包含集合、元数据等
- **说明**: 向量数据库，用于存储和检索 AI 嵌入向量

### `backup/`

- **用途**: 数据库备份文件
- **文件类型**: `.db.backup`, `.sqlite.backup`, 压缩文件等
- **说明**: 定期备份的数据库文件，便于数据恢复

### `logs/`

- **用途**: 数据库操作日志
- **文件类型**: `.log`, `.txt`
- **说明**: 记录数据库连接、查询、错误等操作日志

## 🔧 配置更新

需要更新 `config.json` 中的数据库路径配置：

```json
{
  "database": {
    "sqlite": {
      "path": "database/sqlite/deepwin.db",
      "backup_path": "database/backup/",
      "log_path": "database/logs/"
    },
    "qdrant": {
      "local_path": "database/qdrant",
      "backup_path": "database/backup/qdrant/"
    }
  }
}
```

## 📋 最佳实践

1. **定期备份**: 建议每天备份一次数据库文件
2. **版本控制**: 数据库文件不应提交到 Git 仓库
3. **权限管理**: 确保数据库文件夹有适当的读写权限
4. **磁盘空间**: 监控数据库文件夹的磁盘使用情况
5. **日志轮转**: 定期清理旧的日志文件

## 🚨 注意事项

- 数据库文件包含敏感数据，请妥善保管
- 备份文件可能较大，注意磁盘空间
- 生产环境建议使用专业的数据库备份工具
- 开发环境可以使用内存数据库 (`:memory:`) 进行测试
