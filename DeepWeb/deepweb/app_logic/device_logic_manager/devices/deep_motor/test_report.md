## 使用建议

### 1. 基本使用

```python
from command_phase import CommandPhase

# 获取命令描述
cmd_desc = CommandPhase.get_command_description("motor_set_speed")

# 获取模型类
model_class = CommandPhase.get_command_model("motor_set_speed")

# 验证参数
validated_cmd = CommandPhase.validate_command("motor_set_speed", {"spd": 2.0})
```

### 2. 字符串解析

```python
# 解析命令字符串
result = CommandPhase.parse_command_string("motor_set_speed(2.0, 1)")
# 返回: {'command_name': 'motor_set_speed', 'params': {...}, 'model': ...}
```

### 3. 搜索功能

```python
# 搜索命令
results = CommandPhase.search_commands("位置")
# 返回包含"位置"关键词的所有命令
```

### 4. 语音指令支持

```python
# 获取语音提示
voice_prompts = CommandPhase.get_all_voice_prompts()
# 为大模型提供训练数据
```
